This directory now contains the canonical constitutional line for the integrated 8-phase framework.

## Canonical precedence

The governing document for the complete 8-phase architecture is:

- `phase-0/docs/en/0_Phase_0_Master_Document.md`

If any phase document conflicts with Phase 0 on:

- phase numbering,
- semantic ceiling,
- allowed claims,
- support class,
- publication rights,
- or hardening / downgrade rules,
