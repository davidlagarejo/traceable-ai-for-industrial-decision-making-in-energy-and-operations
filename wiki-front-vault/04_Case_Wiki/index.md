# Case Wiki Index

This is the compounding markdown wiki layer.

It contains:

- reusable knowledge objects
- tension and verification objects
- live case workspaces

This is the layer closest to the Karpathy pattern:

- sources remain immutable elsewhere
- the LLM maintains interlinked markdown here
- contradictions stay visible
- knowledge compounds over time

## Entry points

- [[00_Knowledge_Objects/index]]
- [[01_Cases/index]]

## Rule

This layer should answer case-level questions such as:

- what is poorly understood
- what decision is at risk
- what assumption is fragile
- what should not be done yet
- what to verify first
- what the preliminary financial and regulatory posture is
- how far the case is from verification-grade

This is the main wiki layer. It should stay closer to case logic than to internal framework exposition.
