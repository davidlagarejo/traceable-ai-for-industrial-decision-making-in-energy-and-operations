# Category and Positioning

This product should position around:

- decision integrity under physical uncertainty
- pre-verification industrial intelligence
- capital clarity before expensive diligence

It should also be comfortable framing itself as:

- early decision hardening for physical-asset cases
- a bridge between weak priors and verification work
- a system for not funding or investigating the wrong problem

It should avoid sounding like:

- generic energy software
- generic compliance software
- generic AI copilot
- generic dashboard platform

It should also avoid sounding like:

- traditional consulting
- commodity efficiency software
- generic enterprise AI
- an explainer about internal phases

## Category discipline

The category claim should preserve the actual promise:

- not final answer
- not autonomous decision-maker
- not replacement for audit, M&V, or site verification
- not certainty machine

It is a pre-verification decision system that improves framing, exposes weak assumptions, and directs deeper work.
