# Reference Anchor

## Method

The analysis separates source observations, proxy assumptions, modeled estimates, and validation requirements. Each finding identifies the dataset, method, limitation, and uncertainty.

## Evidence

The report traces tariff data, operating constraints, maintenance indicators, and benchmark comparability. Tables include source provenance and describe why each signal is relevant.

## Financial Logic

Savings are presented as a range with capex, opex, payback, ROI sensitivity, and confidence limits. No modeled savings are described as validated savings.

## Regulatory Logic

Regulatory exposure is discussed as a screening concern, not compliance closure. Permit and standard references are listed as follow-up verification items.

## Recommendations

Recommendations are sequenced by priority, owner, prerequisite, dependency, and verification path.
