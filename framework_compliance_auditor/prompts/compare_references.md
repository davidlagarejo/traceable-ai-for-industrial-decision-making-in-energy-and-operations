# Compare References Prompt

Use this only for quality calibration.

Inputs:
- The report under review.
- Curated reference anchors.
- Deterministic quality metrics.

Task:
Identify where the report is thinner, less rigorous, or less senior-grade than the anchors.

Rules:
- Never say a report violates the framework because a reference does something differently.
- State gaps as comparative quality gaps.
- Keep recommendations actionable and traceable to dimensions.
