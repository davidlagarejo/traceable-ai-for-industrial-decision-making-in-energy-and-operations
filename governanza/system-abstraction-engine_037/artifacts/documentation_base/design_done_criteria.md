# Design Done Criteria — System Abstraction Engine

Motor ID: motor_037

## criteria
- El bundle siempre cubre las once dimensiones estructurales gobernadas con `evidence_state` explícito.
- Casos building y manufacturing reproducen la distinción correcta entre `OBSERVED_FACT`, `CONDITIONAL_HYPOTHESIS` y `ARCHETYPAL_PRIOR`.
- Un target no estructuralmente modelable degrada todo el bundle a `INADMISSIBLE_CLAIM`.
- `system_abstraction_fields` y `system_abstraction_evidence_states` permanecen sincronizados con `system_abstraction`.
- La salida sirve a `motor_038` sin mezclar selección de arquetipo con cierre de variables dominantes o claims downstream.
