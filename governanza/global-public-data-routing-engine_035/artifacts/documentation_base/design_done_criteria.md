# Design Done Criteria — Global Public Data Routing Engine

Motor ID: motor_035

## criteria
- Rutas públicas de NYC, California y Texas producen fuentes obligatorias y prioritarias distintas, coherentes con jurisdicción y tipo de activo.
- Un caso `CORPORATE_HEADQUARTERS` o sujeto no admisible no puede salir con `routing_ready=true` ni con `mandatory_sources` técnicas activas.
- El output siempre incluye bundle estructurado y también señales planas listas para `motor_028`, `motor_012` y packaging downstream.
- Las sustituciones inadmisibles quedan explícitas cuando el caso no admite benchmark o issuer context como reemplazo de evidencia local.
- La recomendación de superficie de reporte queda alineada con la clasificación efectiva y con el estado de readiness técnico.
