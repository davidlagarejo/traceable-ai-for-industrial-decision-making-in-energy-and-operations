# Failure Modes — Financial Exposure Under Uncertainty Engine

Motor ID: motor_045

## expected_failures
- `ROI_LEAKAGE`: aparece ROI final cuando el caso sigue abierto.
- `PAYBACK_PRETENSE`: payback tratado como si ya fuera válido.
- `LAYER_ERASURE`: el registro por capas desaparece o se vuelve superficial.
- `RISK_COLLAPSE`: se pierde la consecuencia de estar leyendo mal el supuesto estructural.

## downstream_risk
- screening tratado como decisión financiera final;
- CAPEX mal secuenciado;
- claims económicos apoyados en evidencia insuficiente.
