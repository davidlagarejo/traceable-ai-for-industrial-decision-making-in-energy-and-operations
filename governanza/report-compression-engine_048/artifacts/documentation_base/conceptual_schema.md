# Conceptual Schema — Report Compression Engine

Motor ID: motor_048

## compression_model

The engine turns a bounded thesis into a bounded hierarchy:

1. primary body outline;
2. client-facing TAD;
3. appendix support surfaces;
4. traceability for what was compressed, demoted or embedded.

It is not allowed to lose the thesis, but it is also not allowed to re-expand the whole runtime into the client-facing body.

## primary_surfaces

- `main_report_outline`: the visible body contract.
- `client_facing_tad`: the compact action surface.
- `appendix_map`: what remains available but not primary.
- `prompt_block_mapping_register`: how original prompt-era blocks map into the compressed structure.

## boundedness_principle

The compression engine has two valid modes:

- `thesis_compressed`: a bounded structural body exists;
- `inadmissible_bypass`: no structural body is allowed yet.

There is no valid middle state where the engine claims inadmissibility but still emits a full structural body.

## congruence_visibility

Congruence signals can be surfaced, but only through selective embedding into existing body sections and appendix support. The engine must keep those signals visible without letting them turn into a parallel report inside the report.
