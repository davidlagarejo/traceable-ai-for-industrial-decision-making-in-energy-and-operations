# Master Concept Doc — Minimum Evidence For Discrimination Engine

Motor ID: motor_046

## core_job

`motor_046` define la evidencia mínima que realmente discrimina hipótesis rivales. No genera checklist genérica; fuerza al framework a pedir sólo la evidencia con mayor valor de información para separar caminos estratégicos incompatibles.

## why_it_exists

Después de `motor_044`, ya existe una hipótesis de rediseño bounded. Falta todavía la disciplina de qué evidencia pedir primero para:

- confirmar una vía;
- falsificar otra;
- y desbloquear el siguiente frente de decisión.

`motor_046` convierte conflicto, framing y rediseño en un set mínimo de pruebas discriminantes.

## behavioral_contract

- Building: debe poder pedir tenant metering map, topology y filing basis, no una lista abierta de “más data”.
- Manufacturing: debe poder pedir throughput, utility bills, equipment inventory y downtime logs como paquete discriminante.
- Cada fila debe decir qué confirma, qué falsifica y qué desbloquea.

## non_goals

- no reemplaza intake completo;
- no pide evidencia irrelevante;
- no emite una lista exhaustiva de due diligence;
- no cierra la hipótesis, sólo define la siguiente prueba mínima.
