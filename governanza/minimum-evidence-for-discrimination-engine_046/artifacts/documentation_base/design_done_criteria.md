# Design Done Criteria — Minimum Evidence For Discrimination Engine

Motor ID: motor_046

## criteria
- Building y manufacturing producen paquetes mínimos distintos y realmente discriminantes.
- Cada fila conserva confirmación, falsificación y unlock.
- `minimum_evidence_for_discrimination_count` permanece sincronizado.
- La salida sirve a intake guidance y priorización sin volverse checklist abierta.
- El paquete mínimo es defendible como el siguiente mejor paso, no como due diligence total.

## review_notes
- El diseño no está terminado si cualquier fila podría resumirse como “gather more data”.
- Tampoco si `unlocks` no cambia materialmente el siguiente paso del caso.
- El cierre formal requiere que un revisor pueda ver por qué esa evidencia discrimina más que otras opciones plausibles.
