# Failure Modes Spec — Minimum Evidence For Discrimination Engine

Motor ID: motor_046

## failure_modes_list
- `CHECKLIST_INFLATION`: la evidencia mínima se vuelve due diligence completa.
- `POOR_DISCRIMINATION`: la evidencia no separa hipótesis rivales.
- `UNLOCK_HOLLOW`: el unlock no cambia nada material.
- `SOURCE_VAGUENESS`: la fuente queda demasiado abstracta para operar.

## anti_patterns
- pedir “más facturas y planos” sin decir para qué;
- mezclar intake amplio con evidencia discriminante;
- olvidar qué hipótesis se pretende falsificar.

## degradation_signals
- filas largas pero poco específicas;
- building y manufacturing comparten el mismo paquete;
- `what_it_confirms` y `what_it_falsifies` suenan iguales.

## expensive_errors
- semanas de recolección de evidencia irrelevante;
- decisiones abiertas por la prueba equivocada;
- falsa sensación de diligencia sin discriminación real.
