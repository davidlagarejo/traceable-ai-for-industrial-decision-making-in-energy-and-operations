# Design Done Criteria — Competitive Comparison Engine

Motor ID: motor_043

## criteria
- Building y manufacturing emiten comparaciones distintas y específicas a su arquetipo.
- Cada fila deja explícito `what_it_proves` y `what_it_does_not_prove`.
- La salida mantiene `transferability` y `evidence_needed`.
- `competitive_comparison_count` permanece sincronizado.
- El output sirve a `motor_044` y a la síntesis ejecutiva sin invadir finanzas o recomendación final.
- `comparison_mode` diferencia con claridad comparación condicional y best practice arquetipal.

## review_notes
- El diseño no está terminado si cualquier fila podría aparecer idéntica en building y manufacturing.
- El cierre formal requiere que un revisor pueda distinguir ventaja estructural de recomendación final.
- También requiere que el peer o práctica mejor desempeñada quede explicable desde benchmark y arquetipo, no desde intuición editorial.
