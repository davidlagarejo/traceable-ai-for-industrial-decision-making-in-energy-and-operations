# Acceptance Tests — Competitive Comparison Engine

Motor ID: motor_043

## acceptance_cases
- Building:
  Debe emitir al menos una comparación condicional donde el mejor performer use submetering, green-lease o disciplina BMS de forma superior.
- Manufacturing:
  Debe emitir al menos una comparación donde aparezcan integración térmica, uptime o process-map maturity.
- Sparse evidence:
  Si la evidencia no soporta peer observado, la salida puede caer a best practice arquetipal pero debe mantener límites explícitos.

## acceptance_threshold
- fila con `what_they_do_better` real y no genérico;
- `comparison_mode` válido;
- `competitive_comparison_count` sincronizado;
- la comparación no puede presentarse como prueba final de waste.
