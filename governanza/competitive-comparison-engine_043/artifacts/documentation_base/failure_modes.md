# Failure Modes — Competitive Comparison Engine

Motor ID: motor_043

## expected_failures
- `BENCHMARK_TO_PROOF_DRIFT`: la comparación se usa como veredicto final.
- `GENERIC_BEST_PRACTICE_SLIP`: el peer se vuelve consultoría genérica.
- `TRANSFERABILITY_ERASURE`: desaparecen límites sobre lo transferible.
- `PEER_TYPE_DRIFT`: se compara contra un peer que no corresponde al arquetipo.

## downstream_risk
- contaminar rediseño y tesis ejecutiva;
- inducir claims comparativos demasiado fuertes;
- producir una falsa sensación de “competidor superior” sin base suficiente.
