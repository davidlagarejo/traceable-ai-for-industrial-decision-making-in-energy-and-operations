# Failure Modes — Conditional Redesign Engine

Motor ID: motor_044

## expected_failures
- `RECOMMENDATION_LEAK`: el rediseño sale como decisión final.
- `NO_KILL_SWITCH`: falta condición de falsificación.
- `GENERIC_DIRECTION`: dirección de rediseño demasiado vaga.
- `ECONOMIC_OVERCLAIM`: la lógica económica se vuelve promesa de ROI.

## downstream_risk
- contaminar finanzas y evidencia mínima;
- endurecer una narrativa de rediseño que aún no está demostrada;
- producir recomendaciones imposibles de falsificar.
