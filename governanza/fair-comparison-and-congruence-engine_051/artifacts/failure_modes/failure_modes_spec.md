# Failure Modes Spec — Fair Comparison and Congruence Engine

Motor ID: motor_051

## failure_modes_list
- `FALSE_COMPARABILITY`: peer frame inválido marcado como comparable.
- `BOUNDARY_SUPPRESSION`: control boundary relevante omitida de la lógica comparativa.
- `CORRELATION_TO_CAUSALITY_JUMP`: correlación estructural usada como causalidad cerrada.
- `GAP_EXTENSION_LOSS`: extensión de gap taxonomy borra o degrada lineage heredado.

## anti_patterns
- usar asset class simple como proxy de fair peer basis;
- esconder contradictions para dejar el caso “más accionable”.

## degradation_signals
- counts de risks o blockers sorprendentemente bajos en casos complejos;
- building sin normalización owner-vs-tenant;
- manufacturing o logistics con comparaciones area-only aprobadas.

## expensive_errors
- construir benchmarks falsos que luego contaminen finanzas o claim governance;
- priorizar acciones estratégicas sobre comparaciones que nunca fueron fair;
- perder riesgos de framing y permitir tesis ejecutivas erróneas downstream.
