# MCP Extension Layer

MCP is optional and secondary for this project. The auditor must work from local files without MCP.

Future MCP integrations can provide:

- Document index access for large contract and reference libraries.
- Internal knowledge-source retrieval with explicit source IDs.
- Developer documentation access.
- Third-party document parsing or citation extraction bridges.

MCP must not become the normative brain of the system. Phase contracts remain local audit contracts, reference documents remain quality anchors, and the report remains the object under review.
