# Build Revision Packet Prompt

Inputs:
- Claim violation register.
- Phase compliance report.
- Reference gap report.

Task:
Convert findings into precise revision instructions for another AI.

Rules:
- Give exact actions: keep, remove, soften, qualify, split, relocate, defer, block, add traceability, add caveat, or add hardening path.
- Include normative phase source for compliance fixes.
- Include comparative reference source only for quality fixes.
- Do not ask the revision AI to invent missing evidence.
