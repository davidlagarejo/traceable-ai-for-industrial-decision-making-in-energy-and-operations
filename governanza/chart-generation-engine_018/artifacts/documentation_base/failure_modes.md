# Failure Modes — Chart Generation Engine

Motor ID: motor_018

## primary_failures

- `FOREIGN_CHART_CONTEXT`: chart assets lose current-case stamping.
- `MODE_COPY_FLATTENING`: blocked, exploratory and structural modes collapse into generic chart copy.
- `TAXONOMY_DRIFT`: chart category, lane or intent metadata disappears or becomes inconsistent.
- `CLAIM_OVERSIGNAL`: the visual framing implies stronger certainty than the evidence posture supports.

## why_these_failures_matter

Charts carry persuasion. If a chart drifts from governance, the report can become visually overconfident even when the text remains bounded.

## required_response

Restore taxonomy, curation-mode separation and case stamping before allowing the asset downstream.
