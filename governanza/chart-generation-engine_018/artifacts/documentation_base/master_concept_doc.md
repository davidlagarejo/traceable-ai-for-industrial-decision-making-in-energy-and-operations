# Master Concept Doc — Chart Generation Engine

Motor ID: motor_018

## core_job

`motor_018` generates publication-grade analytical charts from governed pipeline objects. The charts are asset-first, section-aware, taxonomy-tagged and case-stamped so they can explain the framework's reasoning visually without inventing new claims.

## why_it_exists

Some parts of the framework are better explained visually:

- congruence binding state;
- peer-comparison trust gates;
- cross-layer contradiction maps;
- minimum evidence before measurement escalation;
- gap taxonomy and next-best-search logic.

This motor exists to produce those visuals in a governed way so the charts clarify the analysis instead of becoming decorative or analytically free-floating.

## behavioral_contract

- emit chart assets with taxonomy metadata, bilingual copy and section hints;
- keep charts case-isolated via stamped chart context and case fingerprint;
- adapt curation copy by report mode and blocked/exploratory/structural context;
- preserve chart governance fields such as epistemic marker, support state, data dependencies and chart role.

## non_goals

- it does not invent claims not already supported upstream;
- it does not decide the report mode;
- it does not produce generic presentation graphics detached from the case;
- it does not bypass case isolation or chart taxonomy discipline.

## downstream_role

`motor_018` produces governed chart assets that later package assembly, writing and render validation can place into the report. If this motor drifts, the report can acquire visually persuasive but analytically unsafe charts.
