# Test Spec — Evidence Maturity & Claim Permission Engine

Motor ID: motor_034

## happy_path

- NYC commercial-building case with observed `GFA`, `EUI` and public dataset support upgrades maturity, enables compliance screening and emits a bounded screening report recommendation.
- Strong technical substrate with sufficient technical variables unlocks `Full Technical Decision Intelligence Report`.
- Structural lane inputs activate `canonical_problem_frame`, structural claim permissions and structural output-mode tables while preserving evidence discipline.

## sparse_case

- Missing `GFA` or similar critical variables keeps numeric EUI and ROI claims blocked.
- Partial bounded asset context resolves to `Exploratory Prior Brief` instead of overpromoting to a stronger report.
- Declared-input-only cases stay capped at low maturity and do not silently become decision-grade.

## malformed_input

- empty or malformed optional structural inputs must not fabricate active contradictions, dominant variables or structural promotion;
- missing or weak source evidence must not inflate maturity because a field name happens to exist;
- requested strong report types must be clamped when readiness is below threshold.

## edge_cases

- benchmark-only CAPEX allows directional ROI but not finance-grade scenario claims;
- non-NYC contexts must filter LL97-specific claims and use generic compliance evidence packs;
- public asset-specific LL97 filing artifacts may upgrade `compliance_filing` in NYC;
- sufficiently bound congruence may activate the canonical problem frame even when cross-layer conflict rows are sparse.

## pass_criteria

- every emitted register preserves the documented row shape;
- maturity, claim permission, decision permission and report readiness remain mutually consistent;
- structural activation is possible without forcing a stronger primary report type;
- counts and summary values reconcile with the underlying registers;
- executable coverage in the governing tests passes.

## fail_criteria

- strong claims become allowed under missing critical evidence;
- declared input loses its downgrade;
- LL97 logic leaks outside NYC;
- canonical problem frame never activates when the structural lane is sufficiently bounded;
- a requested full technical report survives despite insufficient maturity.
