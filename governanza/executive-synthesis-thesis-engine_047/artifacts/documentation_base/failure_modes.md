# Failure Modes — Executive Synthesis / Thesis Engine

Motor ID: motor_047

## primary_failures

- `THESIS_SPRAWL`: the engine stops selecting and starts dumping many conflicts or actions.
- `FALSE_ADMISSIBILITY`: structurally unready cases receive a polished structural thesis anyway.
- `UNEXPLAINED_SELECTION`: a dominant contradiction is chosen but the ranking and rejected candidates disappear.
- `FALSE_CAPEX_CONFIDENCE`: bounded financial exposure is rewritten as investable certainty.
- `CONGRUENCE_OVERWRITE`: congruence-specific takes replace the structural center instead of enriching it.

## why_these_failures_matter

This motor controls the executive center of gravity for the report. If it drifts, downstream compression and render integrity drift too. A bad thesis is worse than no thesis because it can be elegant, persuasive and wrong at the same time.

## required_response

When these failures appear, the fix is to restore bounded thesis discipline:

- one contradiction;
- one reframe;
- few actions;
- explicit inadmissibility when needed;
- explicit ranking basis.
