## example
Motor 031 solicita un dataset sintetico para explorar si un detector binario podria distinguir condiciones de alarma en el caso `inf-case-118`. Motor 030 recibe un `expert_problem_spec` aprobado por motor_029, resuelve la version vigente del generador desde motor_002 y emite un run reproducible con 6 filas sinteticas. El resultado sirve solo para exploracion y no puede citarse como evidencia de campo ni sustituir Validation Data Bridge o Verification Bridge.

## notes
The spec must be approved, `handoff_allowed=true`, expert-reviewed and free of unresolved critical ambiguity before generation starts. The generator version must come from a current motor_002 version record; the implementation rejects the run instead of inventing a version or filling missing parameter domains. Repeating the same `expert_spec_ref`, `source_problem_ref`, `generator_version`, `parameter_set` and `generation_seed` produces the same canonical IDs, dataset hash and records, aside from emission timestamps outside the material hash.
